The California Insurance Code
-------------------------------------------------------------------------------------
The California Insurance Code (CIC) is maintained by the California Legislative Counsel Bureau and contains all the laws relating to insurance in California.

To locate a code section in the CIC, follow the link above. Once on the Legislative Counsel Bureau's website, select the "Insurance Code - INS" link.

https://www.insurance.ca.gov/01-consumers/130-laws-regs-hearings/01-CIC/


When the CIC's Table of Contents page opens, you may select the link for the appropriate Division containing the range of code sections that includes the one you are looking for or expand the list to see more sections.

If you choose to Expand all, you will be able to scroll down the list to find the specific code section you are looking for.
