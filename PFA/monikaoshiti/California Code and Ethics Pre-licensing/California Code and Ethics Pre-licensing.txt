California Code and Ethics Pre-licensing

加州保险局 (CDI) 规定，所有申请保险执照的考生必须先完成 12小时 的
《加州保险法与职业道德》(California Insurance Code and Ethics) 预许可课程。
该课程包含 1小时 的保险欺诈内容，且必须由获批的教育提供商授课。

要满足此要求并顺利备考，您可以选择提供中文辅导的在线培训机构，例如：
1.泛宇集团 (TransGlobal)：提供中文讲解的八节在线课程，涵盖考试重点及考古题分析。
2.New Leaf Exams：提供加州人寿与健康保险的中文学习与备考辅助。
3.美国主流机构：如 XCEL Solutions 和 Aceable Insurance 提供标准的12小时道德与法规课程。

"Ethics" 的中文意思是伦理、伦理学、道德规范或道德准则。
它既指代研究善恶对错的哲学分支（伦理学），也常用来形容特定群体或职业所遵循的行为准则，
如商业伦理或医疗伦理。

“Pre-licensing” 在中文中通常翻譯為“考前培訓”、“考前輔導”或“發牌前課程”。
在美國，它是指從事特定行業（如保險、房地產等）前，法律規定必須完成的指定學時培訓課程。
完成後才能獲得參加正式執照考試的資格。

為了讓華人更容易考取執照，許多機構提供中文授課或附帶中文翻譯與字幕的 Pre-licensing 課程。
